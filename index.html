Luma Guardian branch sorter

Import your Guardian doc and every profile is sorted into its element tree by its Branch Theme.

Import the doc

  1. In Google Docs: File, then Download.
  2. Choose Microsoft Word (.docx), Markdown (.md) or Plain text (.txt).
  3. Upload one file, or select several at once. Use Add more files to keep what is already loaded.
    Branch overrides and options

    Extra overrides for this browser only, one per line: from-path => to-path. Rules in branches.json are always applied too. Lines starting with # are ignored.

    Or paste the text

    Select all in the doc, copy, and paste here.
